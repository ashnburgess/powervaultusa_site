# PowerVault USA — Website v2

Multi-page static website for GitHub Pages / VS Code.

## Files
- `index.html` — Home
- `system.html` — The PowerVault System + interactive scenario diagram
- `solutions.html` — Solutions
- `technology.html` — Technology + technical placeholders
- `installation.html` — Installation & Support
- `about.html` — About & Partners
- `contact.html` — Quote inquiry
- `styles.css` — All site styling and responsive behavior
- `script.js` — Mobile navigation, diagram, footer year, mailto inquiry
- `images/` — Corrected logo and favicon assets provided by the user

## Install in VS Code
1. Make a backup of the current repository.
2. Unzip this package; copy its **contents** into the root of your `powervaultusa_site` repository.
3. Allow `index.html`, `styles.css`, `script.js`, and `README.md` to replace the previous versions.
4. Keep the `images/` folder alongside the HTML pages.
5. Preview locally using VS Code Live Server, or open `index.html` in a browser.
6. Commit and push to the GitHub Pages branch.

## Important content notes
- This is a website **starter**, not an engineering specification. The interactive diagram is illustrative.
- The generated diagram and decorative orbit graphic are **concepts**, not photographs of real PowerVault equipment.
- The large image blocks are clearly marked placeholders; substitute genuine company photos or licensed images when available.
- No specific NPS generator model, electrical capacity, switching time, performance claim, warranty, service area, or partnership is asserted. These are pending confirmation.
- The contact form uses `mailto:`: it opens a visitor's default email app. It does **not** send to a server or store lead submissions. A hosted form service/backend is needed for a direct website submission.
- Contact email is carried forward from the original uploaded website (`info@powervaultusa.com`); verify the inbox is operating before publishing.
- Logo used: latest user-supplied left-edge corrected asset; tagline remains separate. The logo files are raster assets, not true vector artwork.
- Google Fonts used (Manrope and DM Sans); system fonts provide an offline fallback.
